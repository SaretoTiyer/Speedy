# 🚚 Speedy

**Aplicación web para la gestión de domicilios y la conexión entre clientes, tiendas y repartidores.**

Speedy es un proyecto de desarrollo web orientado a facilitar la gestión de usuarios y la información relacionada con los servicios de entrega. Cuenta con funcionalidades para administrar diferentes tipos de usuarios y gestionar sus datos mediante una interfaz web adaptable.

## 📌 Características principales

- 👤 **Gestión de usuarios:** administración de clientes, tiendas y repartidores.
- 🔐 **Seguridad de contraseñas:** protección de las contraseñas mediante mecanismos de cifrado hash.
- 🏪 **Perfiles personalizados:** información adaptada al tipo de usuario.
- 🛠️ **Operaciones CRUD:** creación, consulta, actualización y eliminación de registros.
- 🗄️ **Base de datos relacional:** almacenamiento y gestión de información mediante MySQL.
- 📱 **Diseño adaptable:** interfaz desarrollada con HTML, CSS y JavaScript.

## 🧰 Tecnologías utilizadas

| Tecnología | Uso |
|---|---|
| PHP | Lógica del servidor |
| MySQL | Gestión de la base de datos |
| HTML5 | Estructura de la interfaz |
| CSS3 | Diseño y estilos |
| JavaScript | Interactividad del lado del cliente |
| XAMPP | Entorno de desarrollo local |

## ⚙️ Instalación y ejecución

### Requisitos previos

- PHP.
- MySQL.
- Servidor web Apache.
- XAMPP o un entorno equivalente.

### Pasos de instalación

1. Clona el repositorio:

   ```bash
   git clone https://github.com/SaretoTiyer/Speedy.git
   ```

2. Ubica el proyecto dentro del directorio `htdocs` de XAMPP.

3. Inicia los servicios de Apache y MySQL desde el panel de XAMPP.

4. Crea la base de datos de Speedy en phpMyAdmin e importa el archivo SQL del proyecto, si está disponible.

5. Configura las credenciales de conexión a la base de datos en el archivo de configuración correspondiente.

6. Abre el proyecto desde el navegador:

   ```text
   http://localhost/Speedy/
   ```

> **Nota:** los nombres de la base de datos, el archivo SQL y la configuración pueden variar según la estructura actual del repositorio.

## 🎯 Objetivo del proyecto

Aplicar conocimientos de desarrollo web, programación del lado del servidor, gestión de bases de datos y diseño de interfaces para construir una aplicación funcional que organice la información de los participantes en un servicio de domicilios.
